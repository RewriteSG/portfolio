Each presentation is its own static website and has its own HTML, styles, interaction code, and procedural 3D world. They read the shared local Three.js library without changing it. The portfolio narrative is integrated into the presentation chapters; it does not open a separate About page.

The three directions use the Hazwan portfolio content already present in this project's earlier source. These remain design versions for review, rather than assertions of new client engagements or measurable project outcomes.

All added website files are contained in `dist/drafts/`. The existing replica files, assets, rendering code, hosting configuration, and package scripts remain unchanged.
